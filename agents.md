The agents page showcases:

## Quick Reference

### Active Agents
- **Antigravity** (Google DeepMind) - Advanced agentic coding
- **Claude** (Anthropic) - Technical documentation & code review
- **GitHub Copilot** (GitHub/OpenAI) - Real-time code completion

### Workflow Phases
1. **Planning** - Create implementation plans, request review
2. **Execution** - Update tasks, make changes, run tests
3. **Verification** - Test locally, create walkthroughs, validate

### Technology Stack
- Backend: Rust (SysML v2 extension, LSP server)
- Frontend: React, TypeScript, React Flow
- API: OpenAPI/Swagger
- Build: Vite, npm
- Testing: Vitest, Playwright

### Current Initiatives
- Kraken Hub API Server (Phase A)
- Visual Modeling Frontend (React Flow)
- IDE Feature Analysis (Parser & LSP)
- Website Optimization
